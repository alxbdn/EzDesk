# Privacy policy: EzDesk (formerly Desktop Switcher)

*Last updated: November 11, 2026*

EzDesk **does not collect, store or send any personal data**.

- It has no account, no analytics, no telemetry and no ads.
- It doesn't connect to the internet. The only exception is the **Help** item in its tray menu, which opens this project's GitHub page in your web browser.
- It reads which virtual desktop is active, and watches the mouse: when you hold a window by its title bar, and when you scroll over the taskbar, so it can move windows and switch desktops. It doesn't read the keyboard at all.
- It never takes pictures of your screen or your windows.
- The only things it writes to disk are a marker file showing that the welcome notification was already displayed, its settings (`%APPDATA%\EzDesk\settings.ini`), a short log of start-up problems (`%TEMP%\EzDesk-debug.log`), plus a "Run" entry in your user registry if you turn on **Start with Windows** in the zip version.

The source code is public: https://github.com/alxbdn/ezdesk

Questions: open an issue at https://github.com/alxbdn/ezdesk/issues
